Verify a claim

Install pay.sh and set up a funded mainnet USDC wallet. pay curl handles the HTTP 402 payment exchange.

pay curl -i -X POST \
  https://facet.hidden-pond-5e6a.workers.dev/v1/verify \
  -H 'Content-Type: application/json' \
  -d '{"claim":"Apollo 11 landed humans on the Moon in July 1969.","sources":["web"]}'

Check health first. Production uses Solana MPP. No Facet API key is required. Allow at least 120 seconds for the complete request.

Request fields

FieldDetails
claimRequired string, 5–2,000 characters.
contextOptional string, up to 4,000 characters.
source_urlOptional starting URL: the original public document or X/Reddit discussion, up to 2,048 characters. Enable web for documents.
sources
Evidence channels		Where the endpoint may look for evidence: web (search and documents), x (posts and replies), reddit (threads and comments). Select 1–3 channels. Omit to allow all three. These are not provider names or citations.
as_ofOptional ISO date-time. Historical verification is unavailable; omit for normal use.

Use JSON, keep the body within 16 KB, and omit unknown fields.

Read the result

verdict is one of supported, refuted, mixed, insufficient_evidence, or not_fact_checkable.

Inspect atomic_claims for individual findings. Join citations.evidence_id to evidence.id for source text and URLs. Read limitations, next_steps, and research.warnings before relying on the result.

Missing evidence does not mean false. Exact quotations verify provenance, not source truth. Demo results are fictional. Media forensics and historical verification are unavailable.

Payments & freshness

Each request settles $0.05 USDC before research, including inconclusive results and cache hits. Successful responses include payment receipt and settlement-signature headers. Provider cost estimates are informational.

Cached results retain their original checked_at. The usual TTL is 15 minutes; unresolved results are capped at 2 minutes. Inspect cache for age and expiry.

Errors & retries

400: invalid request. 402: payment needed or rejected. 413: body too large. 422: historical date unsupported. 500/502: request or assessment failure. 503: unavailable or busy.

There are no automatic refunds or paid-response recovery. A timeout may occur after settlement, and a fresh retry can charge again. Preserve receipts and inspect the failure before repeating a paid request.
