# Contributing

Run `npm ci`, both typechecks, `npm test`, `npm run build`, and `npm run deploy:check`.

Keep research orchestration independent of data transport, and preserve exact evidence provenance. Add contract tests for provider shape changes and meaningful regression cases for decision logic. Paid live evaluation scripts require your own provider budget.

Use `.env.example` locally and Wrangler secrets in Cloudflare. Never submit `.env`, wallet exports, redemption codes, generated evidence payloads, or private provider run links. Public URLs, documented source claims, and synthetic test fixtures belong in reviewed examples.

Do not label an unresolved verdict as an accuracy win or use a model's answer as evaluation ground truth. Document live-test costs and failures alongside successful examples.
